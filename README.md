# Drum Kit 🥁

## 🎯 Overview
Aplikasi ini dibuat dengan **HTML, CSS, dan JavaScript** murni tanpa framework. Untuk bermain drum menggunakan keyboard dengan animasi sederhana dan efek suara yang nyata

## ✨ Fitur
- Mainkan drum dengan menekan tombol keyboard (`a, s, d, f, j, k, l`).
- Klik tombol pada layar untuk menghasilkan suara drum.
- Animasi tombol ditekan agar lebih interaktif.

## 🛠️ Teknologi yang Digunakan
- **HTML5** → Struktur halaman.
- **CSS3** → Styling, background, dan animasi tombol.
- **JavaScript** → Event listener, pemutaran audio, dan animasi tombol.
- **Google Fonts (Arvo)** → Tampilan font lebih menarik.

## 📂 Struktur Proyek
```
drum-kit/
│── index.html # Halaman utama
│── styles.css # Style untuk tampilan
│── index.js # Logika interaktif drum kit
│── sounds/ # Folder berisi file audio (tom, snare, crash, kick)
│── images/ # Folder berisi gambar drum dll
```



## 🚀 Cara Menggunakan
1. Clone atau download repository ini.
2. Pastikan semua file audio berada di folder `sounds/`.
3. Buka `index.html` menggunakan browser modern (Chrome, Firefox, Edge).
4. Mulailah bermain dengan:
   - Klik tombol drum pada layar.
   - Tekan tombol `a, s, d, f, j, k, l` pada keyboard.
