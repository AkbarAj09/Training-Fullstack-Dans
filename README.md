# 🌐 Personal Portfolio - Akbar Abdurrahman

Website ini adalah **portfolio sederhana** yang menampilkan informasi pribadi, keterampilan, dan kontak dari **Akbar Abdurrahman**.  
Dibuat menggunakan **HTML, CSS, dan sedikit JavaScript** untuk tampilan interaktif.

---

## 🎯 Overview
- Bagian **Hero / Top Container** → Menampilkan nama dan profesi.
- Bagian **Profile** → Foto profil + perkenalan singkat.
- Bagian **Skills** → Menjelaskan skill utama, pengalaman coding, dan fun fact.
- Bagian **Contact Me** → Ajakan untuk berkolaborasi, dilengkapi tombol email.
- Bagian **Footer** → Link sosial media (LinkedIn, Twitter, Website).

---

## ✨ Fitur
- Desain clean dan responsif.
- Memperkenalkan diri dengan cara yang menarik.
- Menampilkan skills dengan ilustrasi/gambar.
- Tombol kontak langsung via email.
- Footer dengan link ke media sosial.

---

## 🛠️ Teknologi yang Digunakan
- **HTML5** → Struktur konten.
- **CSS3** → Styling, typography, dan layout.
- **Google Fonts** → Font *Merriweather* dan *Sacramento*.
- **JavaScript** (opsional) → Untuk interaktivitas tambahan.
- **Assets** → Gambar profil, ikon, dan ilustrasi.
