# Simon Game 🎮

Proyek ini adalah implementasi sederhana dari permainan klasik **Simon Game** menggunakan **HTML, CSS, JavaScript, dan jQuery**.

## 🎯 Overview
- Pada awal permainan, pemain menekan sembarang tombol keyboard untuk memulai.
- Game akan menampilkan satu warna pertama sebagai pola.
- Pemain harus menekan tombol warna yang sama.
- Setiap level baru akan menambahkan satu warna ke pola, dan pemain harus mengingat serta mengulangi seluruh urutan dengan benar.
- Jika pemain salah menekan, permainan akan berakhir.

## ✨ Fitur
- Mulai game dengan menekan sembarang tombol.
- Pola warna dihasilkan secara acak setiap level.
- Efek suara berbeda untuk setiap tombol warna.
- Indikator **Game Over** saat pemain salah menekan.

## 🛠️ Teknologi yang Digunakan
- **HTML5** → Struktur halaman.
- **CSS3** → Styling tombol dan efek game.
- **JavaScript (ES6)** → Logika permainan.
- **jQuery** → Event handling, animasi, dan DOM manipulation.

## 📂 Struktur Proyek
```
simon-game/
│── index.html # Halaman utama
│── styles.css # Style untuk tampilan
│── index.js # Logika interaktif game (dengan jQuery)
│── sounds/ # Folder berisi file audio (green, red, yellow, blue, wrong)
```


## 🚀 Cara Bermain
1. Buka `index.html` menggunakan browser modern.
2. Tekan sembarang tombol pada keyboard untuk memulai permainan.
3. Perhatikan pola warna yang ditampilkan (warna akan berkedip dan terdengar suara).
4. Klik tombol sesuai urutan pola yang diberikan.
5. Setiap level baru akan menambahkan satu warna ke pola.
6. Jika salah menekan, permainan berakhir dan pesan **Game Over** akan muncul.

## 🎵 Suara

- **Red** → `red.mp3`  
- **Yellow** → `yellow.mp3`  
- **Blue** → `blue.mp3`  
- **Wrong** → `wrong.mp3`
